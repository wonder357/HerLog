# 图标套 · 豆包改版

在「豆包」原套双形态图标基础上做的两处替换，样式、网格、线宽、配色与原套完全一致。

- 网格 24×24，主体安全区 2px，线性描边 1.7px，round cap / join
- 未选中 `#8B7988` 线性；选中 `#A82760` 实心；莓色入口 `#A82760` 线性
- 底栏显示 27×27pt，点击热区 ≥44×44pt，胶囊底 `#F7DFEA`

## 两枚重画

| 原图标 | 新图标 | 语义 |

| 体重：折线 + 数据点（趋势） | 体脂秤：圆角方体 + 顶部显示条 + 双脚踏位 + 4 个电极点 | 从「体重变化曲线」改为「设备实体」 |
| 皮肤：星芒（焕肤符号） | 女生侧脸：后脑剪影 + 额-眉-鼻-唇-下巴轮廓 + 头顶发梢 + 独立一缕发丝（按《皮肤管理》参考图归一化） | 从抽象符号改为人物剪影 |

## 怎么用

1. 把 `icons/` 里的 15 个文件覆盖到 `豆包\前端样式\assets\icons\` 与 `豆包\nav\`（两处互为同源，建议同时覆盖，保持字节一致）。
2. 底栏 5 枚必须同属一套，不要逐页换套。
3. 若要套到 01–04 四个主题：只把 `#8B7988` / `#A82760` 两处色值换成该套 theme 的 `--outline` / `--berry`，几何不动。
4. 27px 下：体重可读作「小设备」；皮肤（参考版）在小尺寸偏「新月 + 叶」，44px 以上额、眉、鼻、唇、下巴与发丝均可辨。
5. `备选-圆头版\` 里是上一版「模板头像 + 丸子头」的三态，27px 更干净但形体和参考图不同，需要时可直接换过去。
