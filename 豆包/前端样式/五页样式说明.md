## 4. 逐页结构与口径

### 4.1 首页 `pages/home.html`

顺序：日期 → 「今天」→ 一句状态 → 三个快捷入口（记经期 / 记体重 / 拍照分析）→ 对话区 → 输入条 → 五栏。

- 顶部状态行只读聚合：「经期第 3 天 · 最近体重 58.2 kg」，数据来自已保存记录。
- 对话区展示正常回答态：AI 开场白 + 两个示例问句（点击即发送的示意）+ 用户问句 + 回答 + 回答口径脚注「10 月 21 日–11 月 19 日 · 每天取最后一次测量」。
- 回答只陈述记录与首尾变化（8 次、58.6 → 58.2、−0.4 kg），不做健康判断。
- 输入条占位文案「问问她记：这周体重有什么变化？」；发送键为装饰性上箭头。
- 空态 / 回答中 / 失败重试三态未画，接入时按需求文档补（失败需可重试、资料不足要直说）。

### 4.2 经期 `pages/period.html`

顺序：状态行 → 月份切换 → 星期行 → 月历 → 图例 → 选中日记录 → 历史回顾 → 预测免责说明。

- 状态行：「经期第 3 天」+ 描边标签「11 月 17 日开始」；副行「预计下次开始：12 月 12 日 · 按近 3 次记录估算」。
- 月历 2026 年 11 月（30 天，1 日为周日）：17–19 为实际经期连续色带（17 起、19 选中并标「今天」）；12 / 15 / 22 有感受圆点；末行灰字 1–5 为下月日期，仅作视觉收尾。
- 图例三项：实际经期（实心块）/ 预计开始（虚线描边）/ 有感受记录（圆点）。预计开始按规范只在单日画虚线框，本月无预计日，故只保留图例。
- 当天记录：日期 + 「已记录」标签 + 三个感受 chip（经量 中 / 腹痛 轻微 / 疲惫）+ 两个入口「记录经期」「记录感受」+ 说明「感受与经期日期分开保存，单独记录感受不会新建一段经期」。
- 历史回顾 3 段：11/17（未记录结束，持续 3 天（至今），距上次开始 25 天）、10/23（10/27 结束，持续 5 天，间隔 24 天）、9/29（10/3 结束，持续 5 天，首次记录）。
- 页尾固定说明：「预计日期根据历史记录估算，实际日期可能不同，不作为避孕依据。」——文案全文保留，未改写。

### 4.3 体重 `pages/weight.html`

顺序：最近体重卡（含「记体重」）→ 趋势（分段器 + 折线）→ 记录明细入口 → 一条建议。

- 最近体重：`58.2 kg` 大号数字 + 「11 月 19 日 07:20 · 晨起空腹」+ 全宽主按钮。
- 趋势默认「近 30 天」，可切「近 7 天」；图上 8 个记录点（空心圆 + 末点实心），面积渐隐；脚注「记录 8 次 · 首尾变化 −0.4 kg」「每天取最后一次测量」。缺测日不补值，折线按记录日连接。
- 记录明细入口标注「全部 8 笔」（记录次数统计全部记录，不受趋势时间窗限制）。
- 建议独立成卡且与数据分离：「如果想比较长期变化，尽量在相近的时间和条件下称重；单次波动不代表趋势。」

### 4.4 皮肤 `pages/skin.html`

顺序：主按钮「拍照分析」+ 发送说明 → 最近一次观察（含历史入口）→ 三段观察 → 免责说明。

- 发送说明：「照片会在你确认后发送至模型服务，仅用于本次观察；不保存或重拍不会新增记录。」
- 观察卡：104px 照片占位（抽象渐变 + 相机线稿 + 「面部 · 左颊」）+ 时间「11 月 16 日 21:04」+「AI 观察」「已保存」标签 + 「照片仅本人可见」。
- 三段固定结构：照片中可见 / 看不清的地方 / 下次可留意，各一句描述；不给病名、严重度、百分比。
- 免责说明：「以上为模型生成的观察文字，不构成诊断；某次未提及一种现象，不代表它不存在。」
- 历史入口「历史记录 ›」在区块标题右侧；「两次对比」为可选项，原型未画。

### 4.5 我的 `pages/me.html`

顺序：头像 / 姓名 / 用户名 → 单列表单（用户名只读、生日、身高、电话）→ 保存资料 → 退出登录 → 数据保留说明。

- 用户名 `lin_xiaoyu` 只读灰底，提示「注册后不可修改，用于登录。」
- 生日 / 身高 / 电话均标「（选填）」；电话提示「仅作为个人资料保存，不用于登录，也不会发送验证码。」
- 「保存资料」为主按钮；「退出登录」为 ghost 次按钮，下方说明「退出后账号与健康记录仍保留，重新登录即可查看。」
- 登录 / 注册页不属于本页，按规范不显示底栏。

## 6. 响应式与适配

## 7. uni-app 接入提示（不改源码，仅作改造清单）

1. `src/pages.json`：注册五个一级页 `pages/home|period|weight|skin|me/index`；`tabBar.list` 改为五栏，`iconPath` / `selectedIconPath` 指向 `static/tabbar/` 下 PNG（由 `豆包\png\` 的 81px 三倍图导出）。
2. `src/constants/tabbar.ts` 与 `src/utils/tabBar.ts` 同步五项配置（key、文案、路径、图标）。
3. 自绘底栏 `src/components/tabbar/LiquidTabBar.vue` 内硬编码的旧路径与图标必须替换；选中态底色用 `#F7DFEA`、文字 600、图标取 `*-active.svg`。
4. 一级页跳转用 `uni.switchTab`，二级页（记录明细、历史回顾、拍照分析流程）用 `uni.navigateTo`。
5. 原型里 `px` 可直接沿用（390 基准）；若改用 `rpx`，按 750/390 ≈ 1.923 换算，避免字号出现半像素。
6. 页首渐变可由 `--hero-grad` 直接搬为 CSS 渐变；不要用参考图截图做背景（规范明确禁止）。

## 8. 已知取舍与可选项

- 日历末行灰字 1–5 为下月日期，仅用于收尾视觉，不参与交互；接入时可选择隐藏。
- 首页示例问句为标准胶囊 chip，点击即视为发送；正式版建议第一次点击后隐藏示例。
- 皮肤照片为抽象占位（渐变 + 相机线稿）。参考图不得作素材，真实人像需用户自备或由相机拍摄。
- 体重趋势为静态 SVG 示意（8 个点），接入时按真实记录动态生成；`近 7 天` 切换需重算窗口但记录次数仍统计全部。
- 空态、加载态、失败重试、权限（相册 / 相机）拒绝提示未画，属于接入阶段补充项。
- 我的页未做「修改密码 / 注销账号」等需求文档未列的入口，避免超出范围。
