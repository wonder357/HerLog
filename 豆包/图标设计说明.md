版本 V1.0｜2026-11-19｜依据：需求文档 V0.8、UI/UX 设计文档 V1.0、技术实施说明 V1.0（uni-app / Vue 3 / Pinia）
交付目录：`my-first-project/豆包`（原有 `assets/icons` 与源码均未改动）

---

## 1. 设计思路

**应用图标**：深莓渐变圆角底 + 米白「周期环 + 水滴」。
- 圆环取「周期、循环」，水滴取「经期」，两者构成一个可一眼认出是女性健康记录产品的符号；
- 深莓底（#A82760 → #781946）让图标在手机桌面、应用列表中有足够的存在感，米白（#FFF8FB → #F7DDE9）保证 24 px 下仍有清晰轮廓；
- 造型全部由几何路径构成，无描边文字、无细碎装饰，缩到 40 px 仍可辨识。

**导航图标**：五个一级页共用一套 24 × 24 网格的线性图标（1.7 px 圆头描边），选中态为同形实心版。
- 同一几何语言：主体居中、圆角半径一致、笔画粗细一致，混排时不会出现「风格打架」；
- 选中态镂空处为透明，可直接叠在底栏的 #F7DFEA 胶囊底上，不需要为不同底色另做一套图；
- 每个图标都避开彼此的语义：水滴只属于经期，星芒只属于皮肤。

| 页面 | 图形 | 语义 |
|---|---|---|
| 首页 | 房屋 | 入口 / 今日 |
| 经期 | 日历 + 水滴 | 按日期记录经期与感受 |
| 体重 | 上升趋势线 + 数据点 | 体重页的核心是趋势与明细，比「体重秤」在 27 px 下更清楚、更不易误读为笑脸 |
| 皮肤 | 星芒（大 + 小） | 焕亮 / 拍照观察，与水滴、日历的轮廓完全不同 |
| 我的 | 单人剪影 | 常规个人中心语义 |

> 体重图标说明：早期方案做过「电子秤表盘」，在 27 px 实尺下会被读成表情符号，故改为趋势线；与体重页的折线图、记录明细形成呼应。

## 3. 规格参数

| 项目 | 取值 |
|---|---|
| 图标网格 | 24 × 24（`viewBox="0 0 24 24"`），主体安全区 2 px |
| 线性描边 | 1.7 px，`stroke-linecap="round"`、`stroke-linejoin="round"` |
| 选中态 | 同形实心，`fill="#A82760"`，内部细节做透明镂空 |
| 主色 | 莓色 `#A82760`（选中图标、主按钮） |
| 深莓 | `#8C1D4F`（渐变深端、图标底） |
| 未选中 | 灰紫 `#8B7988` |
| 胶囊底 | `#F7DFEA`（由底栏组件绘制，图标本身不带底色） |
| 页面底色 | `#FAF7FA` |
| 文字主色 | `#2D2430` |
| 图标显示尺寸 | 27 × 27 pt（点击热区 ≥ 44 × 44 pt） |
| 应用图标圆角 | 512 母版半径 114（约 22.3%），iOS / Android 会再按系统规范裁切 |

五个图标都是纯路径 SVG，可任意缩放，不含文字、滤镜和外部依赖，可直接进版本库。

## 4. 导出尺寸

`png/` 内已导出，命名规则：`<名称>-<像素>.png`。

> 应用图标 PNG 一律为**满版方形、不透明**（由 iOS / Android 系统按各自规范裁圆角），直接提交商店或写入 manifest 即可；网页、汇报 PPT 里需要圆角预览时使用 `app-icon.svg`。

| 用途 | 文件 | 尺寸 |
|---|---|---|
| iOS / 通用商店 | `app-icon-1024.png` | 1024 × 1024 |
| 通用 | `app-icon-512.png`、`app-icon-256.png` | 512、256 |
| Android 启动图标 | `app-icon-192.png`、`app-icon-180.png`、`app-icon-120.png`、`app-icon-60.png` | 192 / 180 / 120 / 60 |
| Android 自适应 | `app-icon-maskable-512.png` | 512（满版，系统裁圆） |
| 浅色底版 | `app-icon-light-512.png`、`app-icon-light-180.png` | 512、180 |
| 单色 | `app-icon-mono-512.png` | 512 |
| 底栏图标 | `<页面>-81.png`、`-54.png`、`-27.png`，以及对应 `-active` | 81（@3x）、54（@2x）、27（@1x） |

建议底栏直接用 **81 px** 的 PNG（uni-app 运行时会按 27 pt 渲染，等同 @3x 清晰度）。

## 5. 在 uni-app 中使用

**方式一：原生 tabBar（推荐，直接换图）**

把 `png/` 中 10 个底栏图标放到 `src/static/tabbar/`，在 `src/pages.json` 的 `tabBar.list` 中替换路径（字段顺序与「首页｜经期｜体重｜皮肤｜我的」一致）：

```json
{
  "tabBar": {
    "color": "#8B7988",
    "selectedColor": "#A82760",
    "backgroundColor": "#FFFFFF",
    "borderStyle": "white",
    "list": [
      { "pagePath": "pages/home/index",   "text": "首页", "iconPath": "static/tabbar/home.png",   "selectedIconPath": "static/tabbar/home-active.png" },
      { "pagePath": "pages/period/index", "text": "经期", "iconPath": "static/tabbar/period.png", "selectedIconPath": "static/tabbar/period-active.png" },
      { "pagePath": "pages/weight/index", "text": "体重", "iconPath": "static/tabbar/weight.png", "selectedIconPath": "static/tabbar/weight-active.png" },
      { "pagePath": "pages/skin/index",   "text": "皮肤", "iconPath": "static/tabbar/skin.png",   "selectedIconPath": "static/tabbar/skin-active.png" },
      { "pagePath": "pages/me/index",     "text": "我的", "iconPath": "static/tabbar/me.png",     "selectedIconPath": "static/tabbar/me-active.png" }
    ]
  }
}
```

**方式二：自绘底栏（如 `src/components/tabbar/LiquidTabBar.vue`）**

H5 下可直接引用 SVG（`nav/home.svg`、`nav/home-active.svg`），矢量在任意倍率都清晰；选中项的 #F7DFEA 胶囊底由组件绘制，尺寸 44 × 44、圆角 12，图标居中 27 × 27。改成自绘底栏时，注意同步 `src/constants/tabbar.ts` 与 `src/utils/tabBar.ts` 里的路径常量（技术说明第 45 行提到的三处联动改动）。

**应用图标**

- `app-icon-1024.png` 用于 `manifest.json` 的图标配置与商店素材（满版方形，系统自动裁圆角）；
- `app-icon.svg` 仅用于产品内展示、官网、汇报材料等需要圆角的场景；
- `app-icon-maskable-512.png` 用于 Android 自适应图标（满版方形，图形已在中心 80% 安全区内）；
- 启动屏、通知栏用 `app-icon-mono.svg` / `app-icon-mono-512.png`。

## 6. 修改约定

- 改色：线性图标改 `stroke` 值，实心图标改 `fill` 值，不要动路径；
- 改形：所有路径都围绕 24 × 24 网格绘制，主体不要超出 2–22 的范围，否则底栏里会显大；
- 缩放：按比例等比缩放，不要分别拉伸宽高；
- 选中态与未选中态的轮廓必须同形，避免切换时图标「跳一下」；
- 不要再混入其它图标库（Feather、Material 等）的单品，笔画粗细与圆角会明显不一致。
