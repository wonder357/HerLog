# 她记 HerLog · 渐变主题方案（四套）

> 一句话：结构、文案、间距一律沿用已确认的五页原型，只替换颜色、渐变与材质，做四种「温馨 + 高级」的气质，供你挑一套或挑页混搭。

打开顺序：先开 `风格方案\index.html`（四套并排对比）→ 点某一套的「查看五页 →」进入该套五页画廊 → 点某一页进入完整页面。

## 二、四套共用的“渐变手感”（这是高级感的来源）

1. **页首 = 两层径向光 + 一条主渐变**：不是一条死板的线性渐变，而是“左上/右上各一团柔光 + 主渐变”，光斑用 `rgba` 到透明收尾，所以有空气感；浅色三套再在页首底部加一层 56% 起渐隐到页面色，页首与内容之间没有硬边。
2. **卡片 = 极浅的竖向渐变 + 1px 同色系描边 + 内高光**：卡片从 `#FFFFFF` 到极浅的主题色（如 `#FFF9F6`），顶部一条 `rgba(255,255,255,.9)` 内高光，加一层带主题色的柔和投影。远看是白卡，近看有温度。
3. **主按钮 = 主题色双端渐变 + 内高光 + 彩色投影**：`linear-gradient(180deg, btn1, btn2)` 叠 `inset 0 1px 0 rgba(255,255,255,.28)`，投影带主色，按下去有“实体感”。
4. **底栏 = 毛玻璃**：`rgba(255,255,255,.84)` + `backdrop-filter: blur(16px) saturate(1.6)`，内容从下面透出来一点，不抢页面。
5. **选中态 = 渐变胶囊**：`tab1 → tab2` 的浅渐变胶囊 + 主题色内圈光，配“实心图标 + 主色文字”，未选中是线条图标 + 灰紫。
6. **小标题 = 4px 渐变竖条**：`历史回顾`、`趋势`、`最近一次观察` 左侧的竖条用主题色渐变，替代纯色块，是整套里最显“设计过”的细节。
7. **大字用渐变字**：`经期第 3 天`、`58.2` 用 `background-clip:text` 的主色渐变，比纯色更有层次；其余正文保持高对比，不滥用。
8. 次级元素也都带渐变：分段选择器药丸、chip 标签、头像、照片占位、输入框底色、ghost 按钮。

## 三、与基础版（`前端样式`）的差异

同样的五页、同样的文案与间距，视觉层改了这些：

- 主色从统一的 `#A82760` 换成四套主题色；未选中图标从 `#8B7988` 换成各套的暖灰/灰紫。
- 页面底色从单色 `#FAF7FA` 换成“上浅下略深”的双色渐变，卡片从纯白换成极浅竖向渐变。
- 页首从“一条线性渐变”升级为“双层径向光 + 主渐变 + 底部渐隐”；只有暮光玫瑰是深色页首（白字 + 金色辉光 + 金色发丝线）。
- 卡片圆角从 8px 调到 **12px**，投影改为带主题色的低透明度长投影（更柔、更贵）。
- 底栏改为半透明毛玻璃，选中态改为渐变胶囊；新增小标题渐变竖条、渐变大字、药丸分段选择器。

基础版仍是“规范原样”，这四套是“在规范之上的视觉探索”，两者互不覆盖：

- `豆包\前端样式\` → 原版五页（838 基准、8px 圆角、单主色）
- `豆包\风格方案\` → 四套渐变主题（12px 圆角、主题色、渐变材质）

## 五、怎么改 / 怎么复现

- **只想换色**：改 `tools\build.py` 顶部 `THEMES` 字典里对应主题的 `accent / page / hero / btn1 / btn2 / soft ...`，然后在本目录执行 `python tools\build.py`。不要手改生成的 `theme.css` 与页面，会被下一次生成覆盖。
- **重新截图**：`python tools\shots.py`（需要 `playwright` 与本机 Edge；视口 390×900、@2x、按 `.screen` 元素整页截图）。约 20 张页图 + 4 张画廊 + 1 张总览，耗时 1–2 分钟。
- **新增第五套**：在 `THEMES` 里加一项（复制一套改色值），`build.py` 会自动生成目录、主题 CSS、图标与对比页卡片。

## 六、接入 uni-app / 小程序的提示

1. 颜色全部走变量：把 `theme.css` 的 `:root` 搬进 `uni.scss` 或 `common.css`，组件里只写 `var(--accent)`、`var(--page)`，换主题时只改变量。
2. 页首渐变在本机验证过 `linear-gradient` 多层叠加没问题；小程序端如遇不支持，可退化为“单层线性渐变 + 一张预渲染的柔光 PNG”，视觉几乎一致。
3. 导航图标两态：`icons\` 里 `xxx.svg`（未选中）与 `xxx-active.svg`（选中），颜色已按主题写好；小程序 tabBar 不支持运行时换色，建议直接导出 `iconPath` / `selectedIconPath` 两套 PNG（81×81，透明底）。
4. **日历色带不要逐格单独写渐变**——每格各写一条 135° 渐变会在格子边界出现接缝；正确做法是色带区间内用同一浅底平涂，今天再叠 `inset` 描边。
5. 深色页首（暮光玫瑰）里的文字、标签、状态行都依赖深底，接入时不要把这套的页首色单独换回浅色，否则白字会看不清。
6. 12px 卡片圆角是本方案的探索值；若研发侧已按 8px 落地，改 `--radius-card` 一处即可回到规范值。

## 七、选择建议

- **只想选一套上线**：选 **01 蜜桃奶油**，最稳、最不容易出错，和原规范的粉紫体系同源。
- **想要第一眼“贵”**：选 **02 暮光玫瑰**，深色页首 + 金色辉光在小红书/应用商店截图里最抓人；但它只适合做首页/经期这类“有仪式感”的页，长时间记录页建议配浅色变体。
- **偏中性、白天用得多**：选 **03 杏桃霞光**，赤陶色比粉色更成熟，和体重/皮肤这种“数据页”很搭。
- **不想甜、要理性**：选 **04 雾紫珍珠**，冷调薰衣草在健康类产品里辨识度高。
- **也可以混搭**：例如首页用暮光玫瑰做品牌感，经期/体重/皮肤/我的用蜜桃奶油，只需把两套的 `theme.css` 按页面分别引用（页面级样式互不冲突）。
