# 蜜桃奶油 · 素材版（插画素材使用说明）

> 保留我们原来的蜜桃奶油一套：配色、渐变材质、五页结构、文案、间距全部不动，只把 `assets\背景素材` 里的插画做成头像与页首点缀。原素材文件一个没改。

打开：`01b-蜜桃奶油·素材版\index.html`（五页画廊）；单页直接开 `home.html` / `period.html` / `weight.html` / `skin.html` / `me.html`。

## 二、为什么这样处理才不“土”

1. **不用黑底/白底整图直接贴**：先把 webp 转成带透明通道的 PNG，只留人物，背景交给原来的渐变。
2. **首页用 `mix-blend-mode: multiply`**：素材自带的浅色底在正片叠底后自动“消失”，只剩粉色与金粉压进页首渐变里，不会出现一块矩形边界。
3. **所有插画都有渐隐遮罩**：左侧、底部各一条 `mask` 渐变，人物从页面里“长出来”，而不是切在图边上；首页额外做了底部渐隐，接回原来的页首收尾，不破坏之前的柔和过渡。
4. **头像不抢主视觉**：64px、白描边、同色系投影，和原来的圆形头像尺寸一致，只换内容不换布局。
5. **权重分配**：只让「我的」清楚露脸；首页、皮肤都是“隐约有”，避免五页都变成插画海报。

## 三、文件与改动点

```
01b-蜜桃奶油·素材版\
├─ home.html / period.html / weight.html / skin.html / me.html   五页（仅加了 body class 与装饰层）
├─ theme.css            与 01-蜜桃奶油 完全一致
├─ assets.css           本次新增：插画落位、遮罩、头像样式
├─ assets\
│  ├─ avatar.png        头像 256×256
│  ├─ portrait.png      粉金侧影 720×1280
│  ├─ bloom.png         花中侧影 560×560
│  ├─ hat.png           备选：宽檐帽 560×560
│  └─ crown.png         备选：皇冠剪影 480×829
├─ icons\               与 01-蜜桃奶油 一致
└─ index.html           五页画廊（标题已改为“蜜桃奶油 · 素材版”）
```

页面里的改动只有三处，都是非侵入式的：

- `<body>` 加了 `p-home` / `p-period` / … 用于按页定位装饰；
- `<header class="hero">` 里加了一个空容器 `<div class="hero-art"></div>`；
- 「我的」页把 `<div class="avatar">语</div>` 换成 `<img class="avatar avatar-photo" src="assets/avatar.png">`。

要调节，只改 `assets.css` 里对应的 `.p-xxx` 规则即可（透明度、尺寸、位置、遮罩都在那几行）。

## 四、想换成别的素材

- **换头像**：把新图裁成 1:1 放进 `assets\avatar.png` 覆盖即可，CSS 不用动（`object-position` 控制脸部取景，默认 50% 22%）。
- **换首页背景**：改 `.p-home .hero-art` 的 `background-image` 与 `background-position`；建议仍保留 `multiply` + 左/底双遮罩，否则容易出现矩形边。
- **给经期/体重加素材**：把 `hat.png` 或 `crown.png` 按 `.p-skin` 的写法复制一条 `.p-period .hero-art`，控制宽度 ≤150px、透明度 ≤30%，不要压到日期与数字。
- **换主题色**：这套的素材层与主题无关，把 `assets.css` 与 `assets\` 复制到 02/03/04 任意一套，改 `body class` 前缀即可复用。

## 五、注意

- 素材来自花瓣（huaban）收藏，仅适合当前原型/内部评审；正式上线前请替换为自有版权图或已获授权的插画。
- 素材本身没有改色，靠混合模式与遮罩融进蜜桃奶油；如果你希望更“统一”，可以再用 PS 把粉色调到 `#C0566B` 附近，视觉会更整。
- 这是**新增的一套素材版**，`01-蜜桃奶油`（纯渐变版）以及 02/03/04 三套都原样保留，方便对比。
