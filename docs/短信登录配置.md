# 短信验证登录

登录支持手机号验证码和账号密码。启用短信后，新账号需验证中国大陆手机号并设置用户名和密码。老账号用原密码登录后，可在「我的 → 登录手机号」绑定。登录手机号和资料中的联系电话分别管理。

## 本机演示

以 `ENV=local`、SQLite 和 `HERLOG_SMS_MODE=demo` 启动后端，只绑定回环地址。手机号使用 `1990000` 开头的 11 位测试号。点获取验证码后，代码会显示在表单内。演示不会使用短信服务商。演示验证码只对当前后端进程和当前验证流程有效。

已有本地数据库先备份，再执行 `alembic upgrade head`。演示环境使用现有前端代理连接本机后端。

## 真实短信

1. 在 Python 环境安装后端的 `sms` 可选依赖。已有后端环境可安装 `alibabacloud_dysmsapi20170525>=4.0`。
2. 在后端环境配置 `HERLOG_SMS_MODE=aliyun` 和 `REDIS_ENABLED=true`，沿用服务现有 Redis 连接参数。
3. 配置下列变量，凭据保留在后端运行环境中。阿里云验证码短信模板的变量名为 `code`。[阿里云 SendSms 文档](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2017-05-25-sendsms)
4. 在目标数据库备份后执行迁移，再通过本人可接收短信的测试号码验收收信及登录。

| 环境变量 | 用途 |
| --- | --- |
| `HERLOG_SMS_HMAC_SECRET` | 至少 32 字节的随机密钥，用于保护 Redis 中的验证码摘要和限流键 |
| `HERLOG_SMS_SIGN_NAME` | 已审核的短信签名 |
| `HERLOG_SMS_TEMPLATE_CODE` | 已审核的验证码模板编号 |
| `ALIBABA_CLOUD_ACCESS_KEY_ID` | 具有接口调用权限的后端凭据 ID |
| `ALIBABA_CLOUD_ACCESS_KEY_SECRET` | 对应的后端凭据密钥 |

验证码 5 分钟有效，成功使用后失效。同一手机号每 60 秒最多发送一次。连续输入错误 5 次需重新获取。真实短信模式依赖 Redis，连接异常返回暂不可用。默认关闭短信时，可沿用原用户名注册和登录流程。
