# 她记 · 卡通形象「小胭」设计说明 V1.0

2026-11-19 · 配套文件：`assets/mascot/`（SVG 源文件 + PNG 静态导出 + 透明底 GIF 动图）与 `mascot-sheet.png`（设定页）

> **本文档边界**：只定义卡通形象本身（造型、色彩、线条、表情、用法），不改动 `backend/`，也不替代《前端样式设计规范 V1.0》。
> 形象用色与线条全部取自该规范第 3.1 / 3.4 节，未引入新的品牌色。

---

## 1　形象宣言

她的原型不是动物，是**纸**。是那本「她记」里被翻得最多次的一页——边角卷起，某一页自己站了起来。

所以整个造型只有三件事在说话：一张折过角的纸、一支长在肩上的胭脂花、一颗画在胸口的记录心。没有球面高光，没有渐变玻璃感，没有第二层阴影；所有体积都交给一条 10px 的墨线去交代。这是「纸 · 墨 · 胭脂」在插画层的同一次落笔。

配色是一整条干玫瑰色阶：纸底、纸粉、胭脂花、胭脂、墨。深浅只用来分层，不用来制造情绪；唯一的强调色胭脂红只出现在两处——肩头的花心与胸口的心，和她记里「只有用户的记录才用胭脂」是同一条规矩。

她的性格写在线条里：头身比接近 1:1 的圆角方块，四角半径不一致（上大下小），眼睛只占脸宽的 1/6，腮红比眼睛大。越大越像纸，越小越像糖——所以每个尺寸都重新看过一遍，128px 时仍然认得出折角和心。

画她的过程是先否定三版：花瓣放在脑后像兔耳，书签带在缩略图里像火苗，虚线记录环像加载转圈。最后留下的三处细节都必须是**读不错**的——认错一次，这个形象就废了。

## 2　角色设定

| 项 | 设定 |
|---|---|
| 名字 | 小胭 |
| 身份 | 纸页精灵：她记手册里的一页，被翻过太多次，自己站了起来 |
| 性格 | 记得住、话不多、不催促；提醒方式是把纸条递到你面前 |
| 说话方式 | 永远短句，不感叹号；说「记好了」不说「太棒了！」 |
| 吉祥物职责 | 空状态、记录成功、经期与身体的问候、夜间未记录的陪伴 |

## 3　构成与产品对应

| 造型元素 | 画法 | 对应的产品事实 |
|---|---|---|
| 折角 | 右上角切角 + 深一档的翻折三角 | 纸页手册；「被翻过」这件事本身就是记录 |
| 胭脂花 | 肩头三瓣小花，花心一颗胭脂点 | 身体与周期长在她身上，不是头饰、不是犄角 |
| 记录心 | 胸口一枚胭脂心，墨线收边 | 用户自己记下的那一条；胭脂只给用户数据 |
| 墨线 | 10px、圆头、圆角 | 规范 3.4 节描边语言；不用阴影和高光交代体积 |
| 腮红 | 胭脂粉椭圆，左右不等大 | 亲近的语气，替代参考图里的玻璃球高光 |
| 比例 | 4:5 圆角方块，约 1:1 头身 | 缩到 24px 仍是「折角的纸 + 一颗心」 |

## 4　色板

| 用途 | 色值 | 来源 |
|---|---|---|
| 纸底 | `#FBF6F3` | 规范 `--hr-paper` |
| 主体纸粉 | `#F9DEE4` | `--hr-rouge-soft` 同族加深一档，纸底上才分得出层 |
| 花瓣 | `#F5C8D4` / `#EEA9BD` | `--hr-rouge-mid` 的浅侧 |
| 胭脂（花心、心、主色） | `#B23A55` | 规范 `--hr-rouge` |
| 墨（轮廓、眼睛） | `#4A2331` | `--hr-ink` 的暖向变体，避免纯黑压住粉色 |
| 腮红 | `#EF9FB2` | 胭脂粉 |
| 睡觉的 Zz | `#6B5F66` / `#9A8E93` | `--hr-ink-2` / `--hr-ink-3` |

**没有新增品牌色**：除主体纸粉需要比 `rouge-soft` 深一档（否则在白卡与纸底上都糊成一片）、墨色向暖偏一点（纯 `#2B2229` 压在粉色上过硬）之外，其余全部取自现有令牌。

## 5　表情与使用场景

| 表情 | 画法 | 用在哪 |
|---|---|---|
| 平常 · 开心 | 圆眼 + 一点嘴角 | 通用位、引导页、关于页 |
| 记好了 | 笑眼 + 张口笑 + 两枚星芒 | 保存成功、首次记录完成 |
| 关心 | 眉心上扬 + 小嘴 + 一颗飘起的小心 | 经期不适、质量偏暗需重拍、连续多日未记录 |
| 睡觉 | 闭眼 + 小圆嘴 + Zz，整体倾斜 5° | 夜间模式、当日未记录的空状态 |

## 6　使用规范

1. **最小尺寸**：图标位 24px 起，带表情位 48px 起。小于 48px 时只用「平常」一种表情。
2. **留白**：四周至少留 0.25 倍身宽，她不能被裁切、不能被其他元素压住折角。
3. **描边不改**：10px 是这套形象的骨架，缩小时按比例缩，不要为了「更清楚」单独加粗。
4. **不加高光、不加渐变、不加投影**：体积由墨线和翻折三角交代；投影只允许地平线上那一枚扁椭圆。
5. **不改色**：需要弱化时降不透明度或换成单色线稿（同 tabBar 图标的 `ink-3` / `rouge` 两色切法），不要临时调色相。
6. **不拉伸**：等比缩放，不旋转超过 8°，不镜像（镜像后胭脂花会跑到右边，与折角打架）。
7. **深色底慎用**：纸粉主体在 `#2B2229` 上对比不足，需加一圈纸色描边或放进浅底容器。
8. **她是旁白不是主角**：与文案同现时，她只做补充说明；同一屏不超过一次，不重复出现表情包式排布。
9. **同一屏只让一个动**：动图与静态图混用时，只有一处是 GIF；离开视口就停（`v-if` 卸载或换成静态 PNG），不要让她在后台一直转。

## 7　动图（透明底 GIF）

八组循环动效，全部**没有背景**（GIF 透明索引 + `dispose=2`），可直接叠在页面、卡片、Toast 上，不需要再切图。

| 文件 | 动作 | 时长 / 帧率 | 用在哪 |
|---|---|---|---|
| `mascot-hi.gif` | 抬手挥两下 + 点头呼吸 + 一次眨眼 | 1.2s / 24 帧 / 20fps | 引导页、空状态问候 |
| `mascot-done.gif` | 笑眼张口 + 星芒交替 + 心口一跳 + 小跳（手放下） | 1.2s / 24 帧 / 20fps | 保存成功、首条记录完成 |
| `mascot-idle.gif` | 双手垂着呼吸 + 花朵轻摆 + 3 秒一次眨眼 | 3.0s / 36 帧 / 12fps | 页面角落常驻、等待态 |
| `mascot-sleep.gif` | 双手垂着 + 呼吸起伏 + Zz 上浮淡出 + 倾斜 4° | 2.5s / 28 帧 / 11fps | 夜间模式、当日未记录 |
| `mascot-write.gif` | 手垂下来握笔，笔尖在自己这页上划两下 + 眼睛看笔尖 | 1.2s / 24 帧 / 20fps | 保存中、提交态、首次引导 |
| `mascot-care.gif` | 眉心上扬 + 小嘴 + 一颗小心飘起 + 轻摆 + 偶尔眨眼 | 2.5s / 30 帧 / 12fps | 经期不适、连续多日未记录 |
| `mascot-oops.gif` | `>_<` 眼 + 波浪嘴 + 一滴冷汗滑落 + 小幅摇头 | 1.2s / 24 帧 / 20fps | 空态、加载失败、校验不通过 |
| `mascot-cheer.gif` | 双臂上举 + 连跳两下 + 三颗星 | 1.2s / 24 帧 / 20fps | 连续记录 7 / 28 天、里程碑 |

### 手怎么放，是按表情定的

原画里右手是举着的（挥手位）。如果每张动图都沿用，睡觉、抱歉看起来都像在打招呼，所以每组的胳膊单独调：

| 表情 | 右手 | 左手 | 理由 |
|---|---|---|---|
| 挥手 | 举起，正负 14° 摆两下 | 自然下垂 | 只有「打招呼」才需要举 |
| 记好了 | 垂下，随跳跃轻摆 | 自然下垂 | 情绪在脸和跳，手不必抢戏 |
| 待机 / 睡觉 | 垂下 | 自然下垂 | 静止姿态要「安静」，双手不举 |
| 记录中 | 垂下并握笔，笔尖落在纸页上 | 自然下垂 | 干活的手要低，笔才像真的在写 |
| 关心 | 垂下并微微内收 | 自然下垂 | 收一点显得「护着」，不要张开 |
| 抱歉 | 垂下并微微外撇 | 自然下垂 | 有点束手无策的样子 |
| 庆祝 | 举起摆向斜上 | 举起摆向斜上 | 只有这一组双手都举 |

- `-256.gif` 后缀为 256px 版本（101～163KB），512px 版本为 221～337KB。**移动端优先用 256。**
- 帧序列首尾相接，全部无限循环，接缝处没有跳帧（所有位移都按整周期正弦计算，t=0 与 t=1 同值）。
- **GIF 只有 1-bit 透明**：边缘按 alpha 50% 二值化，所以是硬边。512 / 256 下看不出来，缩到 96px 以下会略显毛边——小尺寸请改用静态 SVG，或找我要 APNG / WebM 版本（支持 8-bit 平滑透明）。
- 调色板每帧量化到 ≤255 色，与原色值有 ±1～2/255 的偏差，肉眼看不出。
- Zz、冷汗、飘起的小心都用 `--hr-rouge-mid #D98396` 而不是墨色，浅底深底都读得出来。

## 9　还可以往下补的

- 第二个动作：记录中（低头写字）、翻阅、合上本子、（经期）抱一下自己——现在四组都是「情绪」，还缺「做事」的动作。
- 平滑透明版本：APNG 或 WebM，边缘不再是硬边，适合放在深色 bg 或放大展示。
- 三视图与侧面：折角在侧面如何交代，决定她能不能进更复杂的位移动效。
- 图标位：`tabBar` 的「我的」、空状态插图、Widget 小图，各需要一份按尺寸重画的版本。
- 出现 / 消失仍按规范第 3.5 节：抬起 8px / 200ms 进，原地淡化 / 160ms 出；四组 GIF 只负责「停留期间」的循环。
